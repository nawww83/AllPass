AllPass — это удобный и безопасный менеджер паролей для хранения учетных данных, управления несколькими хранилищами.

## Ключевые возможности

- Множество независимых хранилищ, привязанных к 5-значному PIN-коду и мастер-фразе
- Мастер-фраза вводится с подтверждением при создании нового хранилища: опечатка не приводит к появлению пустой базы
- Полная поддержка Unicode в мастер-фразе — кириллица, иероглифы, эмодзи, ввод через IME
- Автоматическое резервное копирование и восстановление данных при повреждении или удалении основного файла хранилища
- Генерация паролей разной сложности
- Смена PIN-кода и мастер-фразы с переносом данных
- Подсветка устаревших паролей: жёлтым — если запись не менялась 9–12 месяцев, красным — больше года
- Поддержка USB-ключа для хранения именованного ключа (имя до 64 символов)
- Простой интерфейс для управления записями и восстановления удаленных/модифицированных строк таблицы из хранилища

## Как работает программа

После запуска приложения необходимо:

1. Ввести PIN-код
2. Затем ввести мастер-фразу или подключить USB-носитель с ключом
3. Если подключен USB-ключ, то выбрать ключ из списка по имени

Мастер-фраза запрашивается по-разному:

- **новое хранилище** — дважды: второй раз для проверки, что фраза набрана одинаково;
- **существующее хранилище** — один раз;
- **выбран USB-ключ** — не запрашивается вовсе.

При вводе фраза показывается открыто, чтобы можно было заметить опечатку; флажок «Скрыть фразу» включает маскировку. Копирование и вырезание фразы заблокированы — она не попадает в буфер обмена.

После успешной аутентификации отображается имя активного хранилища, которое соответствует имени файла хранилища.

Если строки таблицы были ошибочно модифицированы, их можно восстановить из активного хранилища (откатить редактирование таблицы).

Если файл хранилища был удалён или повреждён, программа после повторной аутентификации автоматически попытается восстановить данные из резервной копии.

## Где хранятся данные

Все файлы создаются **рядом с исполняемым файлом** (`AllPass.exe` в Windows, `AllPass` в Linux), а не в текущем каталоге процесса:

- хранилище — файл из 32 символов без расширения (имя выводится из PIN-кода и мастер-фразы);
- резервная копия — скрытый файл с тем же именем, начинающимся с точки (в Windows выставляется атрибут «скрытый», в Linux — обычный dot-файл);
- временный файл `*.tmp` — только на время записи;
- копия для отката `<имя>.<старая версия>.bak` — создаётся один раз, когда старая база автоматически переводится в формат 3.02; после успешного обновления её можно удалить вручную;
- при обновлении формата имя файла автоматически приводится к имени нового формата (у старой базы оно было другим); копия `.bak` при этом остаётся под прежним именем.

Поэтому, чтобы открыть свою базу, запускайте `AllPass.exe` из той же папки, где она лежит. При запуске из другого каталога (например, из среды разработки) приложение предложит создать новое хранилище.

## Генерация паролей

Все пароли генерируются в задаваемом диапазоне от 10 до 50 печатаемых ASCII-символов с шагом 5 (по умолчанию 20).

### Уровни сложности

1. Простые — латинские буквы `[aA-zZ]` и цифры `[0-9]` (62 символа)
2. Сложные — латинские буквы, цифры и 15 специальных символов с ASCII-кодами `[33, 47]` (77 символов)

В сложном режиме пароль всегда содержит хотя бы один специальный символ; позиция и сам символ выбираются случайно.

## Дата изменения пароля

Дата хранится в скрытой колонке и показывается через контекстное меню («Показать дату изменения пароля»).

- Пароль, скопированный из этого же хранилища и вставленный в другую строку, переносит свою дату — на сегодняшнюю она не сбрасывается.
- При ручном вводе, вставке из другого приложения или генерации нового пароля дата становится сегодняшней. Если у строки уже была другая дата, приложение спросит: оставить прежнюю или поставить сегодняшнюю.

## Сборка

Нужны CMake 3.16+, компилятор с C++20 и Qt 6 с модулями Widgets, Network, Concurrent.

Windows (Qt 6.11.1, llvm-mingw):

```powershell
$env:PATH = "C:\Qt\6.11.1\llvm-mingw_64\bin;C:\Qt\Tools\llvm-mingw1706_64\bin;" + $env:PATH
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release `
      -DCMAKE_PREFIX_PATH=C:/Qt/6.11.1/llvm-mingw_64
cmake --build build
# файлы Qt рядом с exe:
windeployqt --release --no-translations build\AllPass.exe
```

Linux:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
cmake --install build --prefix ~/.local   # бинарь, .desktop и иконки hicolor
```

Под Windows иконка вшивается в exe ресурсом `app.rc`, под Linux — ставится в тему
hicolor вместе с `packaging/linux/allpass.desktop`.
