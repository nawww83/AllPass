# AllPass - Менеджер паролей

## Вводная часть

Менеджер паролей **AllPass** поддерживает

* Двойное 128-битное шифрование, основанное на LFSR-регистрах, модулированных пилообразным кодом (итог авторского исследования, см. репозиторий lfsr).

* Автоматическое поддержание резервной копии хранилища и восстановление в случае порчи/удаления основного хранилища.

* Множество хранилищ, которые определяются 5-х значным пин-кодом и мастер-фразой, которая может быть произвольным текстом на любом языке (юникод).

* Генерацию паролей, основанную на на LFSR-регистрах, модулированных пилообразным кодом.

* Смену мастер-фразы/пин-кода с переносом данных.

* Подсветку просроченных паролей.

* Выбор уровня сложности паролей.

* Запись мастер-фразы - ключа - на usb-носитель (с версии 3.00).

После запуска программы требуется ввести пин-код и далее мастер-фразу (либо вставить usb-носитель с ключом). При утере мастер-фразы/usb-ключа и/или пин-кода восстановить данные будет невозможно.

После успешной аутентификации отобразится имя активного хранилища. Данное имя соответствует имени файла в корне приложения. Эти файлы (хранилища) можно хранить где-угодно, и при необходимости подменять их простым копированием.

При неудачном удалении строк таблицы можно нажать кнопку восстановления из активного хранилища. После потребуется подтвердить согласие и ввести пин-код. Таблица будет полностью перезаписана таблицей из активного хранилища.

При удалении/порче файла-хранилища программа (после ввода пин-кода и мастер-фразы/usb-носителя с ключом) автоматически восстановит данные из резервной копии.

Генерируемые пароли могут быть длиной от 10 до 50 печатаемых ASCII-символов. В зависимости от уровня сложности пароли могут быть:

1. Простыми: буквы латинского алфавита [aA-zZ] и цифры [0-9].

2. Сложными: буквы латинского алфавита и цифры + специальные символы с ascii-кодами [33, 47].
