AllPass — это удобный и безопасный менеджер паролей для хранения учетных данных, управления несколькими хранилищами и автоматического резервного копирования данных.

## Ключевые возможности

- Множество независимых хранилищ, привязанных к уникальному 5-значному PIN-коду и мастер-фразе
- Автоматическое резервное копирование и восстановление данных при повреждении или удалении основного файла
- Генерация паролей разной сложности
- Смена PIN-кода и мастер-фразы с переносом всех данных
- Подсветка просроченных паролей
- Поддержка USB-ключа для хранения именованного ключа (начиная с версии 3.00)
- Простой интерфейс для управления записями и восстановления удаленных строк из активного хранилища

## Как работает программа

После запуска приложения необходимо:

1. Ввести PIN-код
2. Затем ввести мастер-фразу или подключить USB-носитель с ключом

После успешной аутентификации отображается имя активного хранилища, которое соответствует имени файла хранения.

Если строки были удалены по ошибке, их можно восстановить из активного хранилища.

Если файл хранилища был удалён или повреждён, программа после повторной аутентификации автоматически пытается восстановить данные из резервной копии.

## Генерация паролей

Все пароли генерируются в диапазоне от 10 до 50 печатаемых ASCII-символов.

### Уровни сложности

1. Простые — латинские буквы `[aA-zZ]` и цифры `[0-9]`
2. Сложные — латинские буквы, цифры и специальные символы с ASCII-кодами `[33, 47]`

## Примечания

- Иконки для кнопок взяты с сайта https://icons8.ru
- Все данные защищены и хранятся внутри пользовательских хранилищ
